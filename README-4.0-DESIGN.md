# Мой Маркет 4.0 — Premium Design + Human Assistant

Бул версияда **товарлардын маалыматтары өзгөртүлгөн жок**.

Сакталган файлдар:
- `products.json` — баалар, аталыштар, характеристикалар жана товарлардын тартиби ошол бойдон.
- `categories.json` — категориялар жана алардын тартиби ошол бойдон.

Өзгөртүлгөндөр:
- `index.html` — жаңы premium dark/orange интерфейс.
- `style.css` — жаңы responsive дизайн.
- `app.js` — товарлардын көрсөтүлүшү source order менен калтырылды; жардамчы жай кыймылдайт; чат/корзина логикасы сакталды.
- `assets/assistant-magnify.png`
- `assets/assistant-laptop.png`
- `assets/assistant-clipboard.png`

Эскертүү: `logo.webp`, `hero.webp` жана `assets/products/*` сыяктуу учурдагы товар сүрөттөрүн өчүрбөңүз. Алар сиздин азыркы сайттагы файлдар бойдон калат.
