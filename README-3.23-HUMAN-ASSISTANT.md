# Мой Маркет 3.23 — Human Online Assistant

- Эскиздеги роботтун ордуна классикалык премиум 3D адам-ассистент кошулду.
- `assets/robot-animated.webp` — 8 кадрдык адам ассистент анимациясы.
- `assets/robot-frames/robot-1.png ... robot-8.png` — чаттагы кадрлар.
- Ассистент hero бөлүгүндө солдон оңго/кайра басып өтөт, басуу учурунда кадрлар жана дене кыймылы синхрондолот.
- Floating Online жардамчы да ошол эле жаңы ассистент менен иштейт.
- Корзина, чат, KG/RU, жеткирүү жана WhatsApp функциялары сакталды.
