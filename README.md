# Мой Маркет — Secure Admin Architecture

Бул пакет GitHub Pages storefront + Admin UI үчүн даярдалды.

## Маанилүү коопсуздук
GitHub Pages статикалык болгондуктан, **чын эле “бир гана мен кирем” деген коопсуз Admin Panelди frontend JavaScript менен жасоого болбойт**. Бул пакетте Admin UI жана 10 админ логикасынын макети бар, бирок production режимде OAuth/backend милдеттүү.

Production архитектура:
- GitHub Pages — public storefront
- Secure backend/serverless function — admin API
- OAuth/Auth — админди текшерүү
- GitHub token — серверде гана
- 1 owner + максимум 9 кошумча admin = 10 орун
- “Администратор кошуу” — owner гана
- Товар кошуу/өзгөртүү/өчүрүү — уруксат берилген adminдер
- GitHub Contents API — backend аркылуу
